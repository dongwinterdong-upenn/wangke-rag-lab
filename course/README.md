# 课程资料

AI FDE 工程师就业实训营的全部文字资料，是 RAG 实训的检索语料与评测集。来源，格式与换算规则见下文。

## 一 目录与规模

| 目录 | 内容 | 规模 | 格式 |
| --- | --- | --- | --- |
| `课件` | 第一周 Day 1 到 Day 5 的课件 | 5 份，536 页 | PDF |
| `讲义` | 第一周 Day 1 到 Day 5 的学生讲义 | 5 份，213 页 | PDF |
| `转写` | 5 场课程录屏的逐字转写 | 2409 句，约 22.6 万字 | Markdown 与 JSON 各一份 |
| `目录` | 平台上 4 章 16 讲 90 节的目录 | 16 讲 | Markdown 与 JSON 各一份 |
| `知识点全览.md` | 按讲整理的知识点摘要，懂妈现有版本的知识底稿 | 约 1.7 万字 | Markdown |
| `测评` | 6 套测评卷，含答案，解析与出处 | 400 题 | JSON |

课件与讲义是同一周内容的两种写法。课件是上课投屏用的，一页一个要点，图多字少。讲义是给学员课后读的，段落完整，修正过课件里的笔误。

## 三 转写

每场录屏两份文件，内容相同：

- `L2_逐字转写.md`：给人读，每句一行。
- `L2_转写.json`：给程序读，每句一条记录。

JSON 每条记录的字段：

| 字段 | 含义 |
| --- | --- |
| `录屏` | 录屏编号，L1 到 L7 |
| `录屏内秒` | 这句话在整场录屏里的秒数 |
| `时间` | 同一个时间写成时分秒 |
| `说话人` | 讲师，嘉宾，助教，学员A，问号表示没识别出来 |
| `文本` | 这句话的内容 |
| `讲次` | 这句话在平台第几讲，1 到 16。L1 没有讲次，课间与等待被剪掉的部分也没有讲次，都为 null |
| `讲内秒` | 这句话在那一讲里的秒数，就是学员在平台播放器里看到的时间 |

`讲次` 与 `讲内秒` 是按平台的切讲方案从 `录屏内秒` 换算出来的，换算规则在 `db/content/fde_lessons.json`：一讲由录屏里的一段或几段组成，每段按 10 秒一片记起止片号。引用转写时用讲次与讲内秒，学员才能在播放器里找到那一段。

转写是语音识别的结果，有同音字错误，专有名词尤其多。人名，个人信息与一处口头念出的数据库口令已经隐去，换成“某同学”“讲师”这类说法。另有 7 句整句删去，留了一句括号说明。

## 四 测评

`测评/测评题库.json` 是 6 套卷，结构是试卷数组，每套卷带一个题目数组。每道题的字段：

| 字段 | 含义 |
| --- | --- |
| `题号` | 题库编号，如 `B-P1-04` |
| `题型` | SINGLE 单选，MULTI 多选，JUDGE 判断 |
| `题干` `选项` | 选项是 `{key, text}` 数组，判断题没有选项 |
| `答案` | 单选是一个字母，多选是按字母顺序排列的几个字母，判断题是 T 或 F |
| `解析` | 为什么选这个，错的选项错在哪 |
| `板块` `考点` `难度` | 难度 1 到 3 |
| `出处讲次` `出处讲内秒` | 这道题出自平台第几讲的第几秒 |
| `出处原话` | 讲师在那个时间点说的原话 |

| 试卷代码 | 名称 | 题数 | 有出处 |
| --- | --- | --- | --- |
| `FDE_MAIN` | 课程综合测试 | 100 | 100 |
| `FDE_CH1` 到 `FDE_CH4` | 四章各一套 | 各 50 | 各 50 |
| `AIGC_OPEN` | AIGC 内容生产能力测试 | 100 | 0 |

300 道课程题的出处已经核对过：出处原话都能在对应讲次的转写里找到，294 道与标注时间相差 60 秒以内，其余 6 道在 300 秒以内。`AIGC_OPEN` 考的是数据标注，文生图，剪辑这些课程之外的内容，没有出处。

测评集只用来评测，不能放进检索语料。放进去等于把答案递给了模型，测出来的分数没有意义。
