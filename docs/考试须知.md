# 考试须知

本仓库用于 2026 年 10 月 23 日的 RAG 实操考试，时间是北京时间 14:00 到 19:00，共 5 小时。考试在服务器上做：在自己的服务器账号里把懂妈跑起来，给她加上 RAG，评测改造前后的效果，19:00 前把提交材料发到群里。

## 一 开考前

- 确认自己电脑能用 `ssh` 登录服务器。Windows 10 与 11 的 PowerShell 自带 `ssh` 与 `scp`。
- 不需要安装 Docker。

服务器怎么用，见 [考试服务器指南](考试服务器指南.md)。

## 二 DeepSeek 密钥

- 密钥已经写在服务器上自己的 `~/lab.env` 里，登录后自动加载为环境变量 `DEEPSEEK_API_KEY`。
- 全体考生共用这一把，余额有限。评测脚本的并发不要超过 5，不要反复整套重跑，调试时先用十几道题。
- 密钥只从环境变量读，不要写进代码，截图与提交包。
- 密钥报错或余额用完，在群里说，不要自己另找密钥。

## 三 建议的时间安排

| 时间 | 做什么 |
| --- | --- |
| 14:00 到 14:30 | 登录服务器，把现有的懂妈跑起来，在平台答疑页问几个问题，读开发要求 |
| 14:30 到 15:00 | 写评测脚本，先用它测一遍**改造前**的懂妈，记下数字 |
| 15:00 到 17:45 | 开发 RAG：解析资料，切片，建索引，检索，生成，出处 |
| 17:45 到 18:15 | 停掉旧懂妈，起新懂妈，用同一个评测脚本测改造后的效果 |
| 18:15 到 18:50 | 写设计说明与评测报告，截图，打包下载 |
| 18:50 到 19:00 | 在群里提交 |

改造前的数字一定要在动手改懂妈之前测，改完再想测就要把旧版本切回来。

## 四 任务里的“部署”与“发布”指什么

- **部署并成功启动懂妈**：在自己的服务器账号里把现有的 `dongma/serve.mjs` 跑在自己的懂妈端口上，在自己那套平台的答疑页提问能得到回答。平台本身已经部署好。
- **发布新版懂妈**：停掉旧懂妈，把 RAG 版懂妈跑在同一个端口上，在自己那套平台的答疑页提问能得到带出处的回答。

## 五 提交

19:00 前在群里发一个 zip 包，文件名是 `姓名_懂妈RAG.zip`，里面包括：

| 内容 | 位置 |
| --- | --- |
| 新的懂妈服务全部代码，包括建索引的代码与启动命令 | `dongma` 目录，或者新建的目录 |
| 评测脚本，评测原始记录 | `eval` 目录 |
| 评测结果报告：检索命中率，答题正确率，响应时间，改造前后对比 | `eval/评测报告.md` |
| 设计说明，附 5 个提问的截图 | `docs/RAG设计说明.md`，截图放 `docs/截图` |

不要放进 zip 的：`lab.env`，模型文件，索引文件，`course` 目录，`node_modules`。

打包与下载的命令见 [考试服务器指南](考试服务器指南.md) 第七节。各项要求的细节见 [RAG 实训开发要求](RAG实训开发要求.md) 第六到第八节。

考试结束后服务器上的代码保留，老师可能直接登录查看与复现评测数字。
