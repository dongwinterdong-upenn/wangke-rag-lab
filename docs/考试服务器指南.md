# 考试服务器指南

10 月 23 日的实操考试在服务器上做，不用在自己电脑上装 Docker。每位考生有一个服务器账号，一套已经部署好的网课平台，以及一个留给懂妈的端口。考生要做的是在这个端口上先把现有的懂妈跑起来，再把它改造成 RAG 版。

## 一 老师发的信息

| 项目 | 说明 |
| --- | --- |
| 服务器地址 | 47.113.150.221 |
| 账号与密码 | 每人一个，例如 `rag01` |
| 平台地址 | 每人一个端口，例如 http://47.113.150.221:9001 |

其余设置都在服务器上自己家目录的 `~/lab.env` 里，每次登录自动加载成环境变量：

| 变量 | 含义 |
| --- | --- |
| `DONGMA_API_PORT` | 懂妈要监听的端口，平台按这个端口调懂妈 |
| `DONGMA_API_HOST` | 懂妈要监听的地址，固定是 127.0.0.1 |
| `DONGMA_API_TOKEN` | 平台调懂妈时带的令牌 |
| `DEEPSEEK_API_KEY` | 考试用的 DeepSeek 密钥 |
| `DONGMA_MODEL` | DeepSeek 模型名 |
| `DONGMA_WORKSPACE` | 懂妈的人设与知识文件所在目录 |
| `PLATFORM_URL` | 自己那套平台的地址 |
| `PLATFORM_STUDENT_PHONE` `PLATFORM_STUDENT_PASSWORD` | 平台学员账号 |
| `PLATFORM_ADMIN_PHONE` `PLATFORM_ADMIN_PASSWORD` | 平台超管账号 |
| `DB_NAME` `DB_USER` `DB_PASSWORD` | 自己那套平台的数据库，可以用来查看提问记录 |

执行 `cat ~/lab.env` 查看全部取值。这个文件里有密钥，不要外传，不要放进提交包。

## 二 登录

Windows 用 PowerShell，macOS 与 Linux 用终端：

```bash

```

把 `rag01` 换成自己的账号。第一次连接会问是否信任这台服务器，输入 `yes` 回车，再输入密码。密码输入时屏幕上不显示，输完回车即可。

登录后的目录：

| 位置 | 内容 |
| --- | --- |
| `~/wangke-rag-lab` | 本仓库，课程资料，开发要求都在里面 |
| `~/lab.env` | 考试环境设置 |
| `~/logs/platform.log` | 自己那套平台后端的日志，懂妈调用失败时这里有记录 |
| `~/logs` | 自己服务的日志也放这里 |

## 三 把现有的懂妈跑起来

这是考试步骤里的“部署并成功启动懂妈”：

```bash
cd ~/wangke-rag-lab/dongma
nohup node serve.mjs > ~/logs/dongma.log 2>&1 &
echo $! > ~/dongma.pid
sleep 3
curl -s http://127.0.0.1:$DONGMA_API_PORT/health
```

最后一行输出 `{"ok":true,` 开头的一行就是起来了。`serve.mjs` 从环境变量读端口，令牌与密钥，不用改代码。

然后在浏览器打开自己的平台地址，用学员账号登录，进答疑页问一个课程问题，几秒内懂妈开始作答。登录页选密码登录。

停掉懂妈：

```bash
kill $(cat ~/dongma.pid)
```

上面三行启动命令要分开执行，`echo $!` 记下的才是懂妈本身的进程号。记错了或者文件丢了，按端口找到进程再结束：

```bash
ss -ltnp "sport = :$DONGMA_API_PORT"
kill 进程号
```

第一条命令输出里 `pid=` 后面的数字就是进程号。自己写的新懂妈也照这个办法停。

改造前的评测要在这时做，见 [RAG 实训开发要求](RAG实训开发要求.md) 第六节。

## 四 开发 RAG 版懂妈

新的懂妈可以用任何语言写，要求只有一条：监听 `127.0.0.1:$DONGMA_API_PORT`，实现开发要求第三节的接口。平台已经接好这个端口，旧懂妈停掉，新懂妈起来，平台就用上新的了。

开发要求里提到的 `compose.yaml` 与 Docker 是本机部署用的，服务器上不用。

### Python 环境

服务器上是 Python 3.10，用虚拟环境装依赖：

```bash
python3 -m venv ~/venv
source ~/venv/bin/activate
pip install fastembed jieba rank_bm25 pymupdf
```

登录时已经设好：

- pip 走阿里云镜像。
- `HF_ENDPOINT` 指向 hf-mirror.com，Hugging Face 上的模型会从镜像下载。
- 临时文件放在 `~/tmp`。

Node 24 已在 PATH 里，`node` 与 `npm` 直接可用。

### 长时间运行

建索引，跑评测这类耗时的命令，用 `nohup` 放到后台，或者在 `tmux` 里跑。这样断开 SSH 也不会中断：

```bash
tmux new -s work
```

断开后重新登录，执行 `tmux attach -t work` 回到原来的窗口。

## 五 资源限制

服务器上同时跑着线上的网课平台，每位考生的资源有上限：

| 资源 | 上限 | 超出时 |
| --- | --- | --- |
| 内存 | 1.5G，自己启动的所有进程合计 | 占用最多的进程被系统结束，日志里只剩半截，进程退出码 137 |
| CPU | 1.5 个核 | 变慢，不会被结束 |
| 磁盘 | 两位考生共用 8G | 写不进去，报 No space left on device |

所以：

- 向量化分批，批大小 16 左右，不要一次把全部片段送进模型。
- 不要装带显卡依赖的 PyTorch，几个 GB 的磁盘一下就满了。只用 CPU 时选 fastembed 这类基于 ONNX Runtime 的库，或者装 PyTorch 时加 `--index-url https://download.pytorch.org/whl/cpu`。
- 向量模型选小的，例如 bge-small-zh-v1.5。
- 用 `free -m` 看内存，`df -h ~` 看磁盘。

## 六 注意

- 只在自己的家目录里工作，自己的服务只监听自己的懂妈端口，地址用 127.0.0.1。
- 不要尝试访问别人的目录，别人的端口，或者线上平台。
- 平台后端由老师管理，考生不能重启。平台后端有问题，在群里说。
- 评测脚本直接调 `http://127.0.0.1:$DONGMA_API_PORT/ask`，令牌是 `$DONGMA_API_TOKEN`，并发不要超过 5。

```bash
zip -r ~/submit.zip dongma eval docs -x "*/node_modules/*" "*/models/*" "*/index/*" "*/__pycache__/*"
```

新建的目录要一并列在 `zip -r` 后面。再在自己电脑上下载这个文件，Windows 用 PowerShell：


下载到的是当前目录。截图在自己电脑上，在本机打开 zip，把截图放进 `docs/截图` 目录，再把 zip 改名为 `姓名_懂妈RAG.zip`。确认里面没有 `lab.env`，没有模型与索引文件，19:00 前发到群里。也可以先用 `scp 截图文件 rag01@47.113.150.221:~/wangke-rag-lab/docs/截图/` 把截图传到服务器再打包。zip 里要有的内容见 [考试须知](考试须知.md) 第五节。
